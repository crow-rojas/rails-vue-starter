# ADR-004: Internationalization

- Status: accepted
- Date: 2026-10-21
- Deciders: owner

## Context

The app ships in English, with Spanish as the second language, and more may come. Copy lives on both sides of Inertia: flash messages and emails in Rails, everything else in Vue. Two translation systems would mean two formats and two places for agents to forget a key.

## Decision

- One source: `config/locales/{en,es}.yml`. Interface copy lives under `ui.`, and Vue calls it by its full key, `t("ui.settings.profile.save")`, so a grep finds both the use and the translation.
- Delivery: `InertiaController` shares the current locale and its `ui` translations as an Inertia once prop keyed by locale, so they travel once per visit and again only when the language changes. `useI18n` reads them with i18n-js, which follows Rails' semantics (`%{name}` interpolation, `one`/`other` plurals), so one YAML file means the same thing on both sides. It costs about 26 KB gzipped (it brings lodash, bignumber.js and make-plural); we keep it because it is well maintained and also covers fallbacks and Rails date and number formats if the app needs them.
- Language: the user's saved choice (profile settings), then the first supported language in `Accept-Language`, then English. Emails use the recipient's language. No locale in the URL.
- Sensors: `i18n-tasks health` in `bin/check` fails on missing, unused or inconsistent keys across Ruby, ERB and Vue; `vue/no-bare-strings-in-template` rejects literal copy in templates and `Rails/I18nLocaleTexts` in controllers and mailers; missing translations raise in development and test.
- Formatting: dates and numbers use the app's locale (`toLocaleString(locale)`), not the browser's.

## Alternatives not taken

- vue-i18n with exported JSON: idiomatic in Vue, but its message format differs from Rails (`{name}`, pipe plurals), so the same key would need two spellings or a conversion step.
- Sending all translations on every request: simple, but the dictionary grows with the app; once props send it once.

## Triggers that reopen this ADR

| Topic | Reopens when |
|---|---|
| Locale in the URL | Public pages need search ranking in more than one language. |
| Splitting the dictionary | The `ui` translations get large enough to slow the first visit; split them per page with once props. |
| Typed keys | A wrong key slips past `i18n-tasks`; generate a key type from the YAML. |
