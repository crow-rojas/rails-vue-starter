# rails-vue-starter: agent guide

A starter for Rails apps with an Inertia + Vue frontend, PostgreSQL and Kamal, built to be developed mostly by coding agents. This file is an index: each rule points to the tool that enforces it.

## Commands

- `bin/setup`: install gems and packages, write `.env` with a free database port, start Postgres in Docker, prepare the databases and run the app. `--skip-server` stops before the dev server.
- `bin/dev`: run Rails and Vite (port from `PORT`, default 3000).
- `bin/ci`: every check CI runs (`config/ci.rb`). **You are done only when it is green.**
- `bin/rails test`, `bin/rails test:system`: Minitest unit, integration and browser tests.
- `pnpm lint`, `pnpm format`, `pnpm check`: ESLint, Prettier and the Vue type check.

## Map

- `app/javascript/pages`: Inertia pages, one Vue component per controller action.
- `app/javascript/components/ui`: shadcn-vue primitives. `app/javascript/components`: app components.
- `app/javascript/types/serializers`, `app/javascript/routes`: generated by Typelizer from the serializers and routes. Never edit them by hand; `bin/ci` fails when they are stale.
- `app/serializers`: Alba resources that define every prop a page receives.
- `docs/adr`: decisions. `docs/research/versions.md`: pinned versions and their sources.

## Rules

1. **English for everything in the repo**: code, docs, commits, PRs, logs and errors. End-user copy is translated (English default, Spanish second); conversations with agents can be in any language.
2. **Conventional Commits**, one concern each, with no AI co-author trailers.
3. **pnpm only.** Never use npm or yarn, and never add a release-age or trust-policy exclusion to `pnpm-workspace.yaml` (ADR-001).
4. **New dependencies need a reason** recorded in `docs/research/versions.md` with an official source.
5. **If a rule gets in the way, propose an ADR.** Do not break it, weaken a check, or skip a hook.
